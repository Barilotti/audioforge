# ADR-0002: Доменная модель — Layer/Clip, неизменяемый документ, Commands и Undo

- **Статус:** принято
- **Дата:** 2026-11-18
- **Связано:** архитектура v0.2, разделы 1.3–1.4

## Контекст
В ТЗ Layer одновременно и клип, и канал. Операция Split ломает такую модель. Нужны надёжный Undo/Redo, фоновое автосохранение и безопасная передача состояния движку.

## Решение
- **Layer** — строка таймлайна (имя, цвет, gain, pan, mute/solo, цепочка эффектов, группа). **Clip** — фрагмент материала внутри слоя (ассет, позиция, source in/out, gain, fades, reverse, выбор каналов, цепочка Clip FX).
- Документ неизменяем: узлы `std::shared_ptr<const T>`, правка создаёт новые копии только изменённых узлов (структурное разделение).
- Все изменения — только через `Command` (чистая функция `Document → Result<Document>`) и `Transaction`; непрерывные жесты коалесцируются в одну запись.
- `UndoHistory` хранит корни документов; Undo — возврат предыдущего корня.
- Ссылки между сущностями только по UUID.

## Последствия
- Undo не может «сломаться» из-за ошибки в ручном `revert()`.
- Снимки документа потокобезопасны без блокировок.
- Нужно следить за памятью истории (лимит, аудиоданные вне модели).
