# ADR-0007: Языки проекта и архитектура локализации (D5)

- **Статус:** принято с уточнением
- **Дата:** 2026-11-18

## Решение
- Код, идентификаторы, комментарии, сообщения коммитов и основной интерфейс — на английском.
- Документация (`docs/`) и общение — на русском.
- Архитектура локализации рассчитана на **полноценную украинскую локализацию** (и далее русскую):
  - все строки интерфейса — только через слой локализации (`TRANS()` / таблицы строк), без строковых литералов в UI-коде; проверка в CI;
  - сообщения с числами — через правила множественного числа CLDR (у украинского и русского четыре категории: one, few, many, other), а не через склейку строк;
  - числа, даты, длительности и единицы форматируются по выбранной локали;
  - шрифты интерфейса с полной кириллицей, включая украинские і, ї, є, ґ и апостроф;
  - макеты рассчитаны на строки длиннее английских на 30–40%;
  - язык переключается в настройках; при отсутствии перевода строки показывается английский вариант;
  - проверка полноты перевода и неиспользуемых ключей в CI;
  - строки сообщений об ошибках тоже локализуются; журналы и минидампы остаются на английском.

## Последствия
- С этапа S0 в UI-коде нет «голых» строк: всё через `TRANS()`.
- Правила множественного числа CLDR для en/uk/ru реализованы в `core/PluralRules` (S0.4) и покрыты тестами.
- Формат файлов перевода и переключатель языка вводятся вместе с первым переводом (когда в интерфейсе появится содержательный текст), отдельным ADR.
