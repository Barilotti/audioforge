# ADR-0008: Формат проекта и хранение времени (D7, D12)

- **Статус:** принято
- **Дата:** 2026-11-18
- **Связано:** архитектура v0.2, разделы 5.1–5.3

## Решение
- Проект — папка с JSON-файлом `.afproj` (`formatVersion`, цепочка миграций, стабильный порядок ключей, атомарная запись). SQLite для проекта не используется.
- Позиции на таймлайне, длины fade, маркеры — `TimeTicks` (int64, 1 тик = 1/705 600 000 с), записываются JSON-целыми.
- Позиции внутри исходного файла (`sourceInFrames`, `sourceOutFrames`) — целые сэмплы файла.
- Строгая валидация: время должно быть JSON-целым в пределах |x| ≤ 2^53 − 1; дробные числа, экспонента, строки и переполнение — ошибка загрузки с указанием поля.
- Длина таймлайна Event ограничена 24 часами (проверяется валидатором модели).
- `timebase` записан в файле; смена единицы — только через миграцию.

## Последствия
- Значения времени точно читаются любым JSON-парсером, включая парсеры на double.
- Тест со сторонним double-парсером в CI.
