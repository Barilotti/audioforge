# ADR-0009: Репозиторий, среда разработки и процесс (D1, D4)

- **Статус:** принято
- **Дата:** 2026-11-18

## Решение
- Новый приватный репозиторий GitHub `audioforge`.
- Разработка в облаке (Linux), Windows-сборки и тесты в GitHub Actions на каждом PR.
- Ручная проверка сборки каждого этапа на Windows-ПК владельца по чек-листу этапа.
- Одна задача = один PR; CI (Windows MSVC, Linux Clang, RTSan) и тесты обязательны.
- Переход к следующему этапу — только после закрытия всех критериев готовности текущего, включая ручную проверку на Windows.
- Каждый этап заканчивается установимой сборкой с тегом `v0.1.0-sN`.
