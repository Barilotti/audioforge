# ADR-0011: Минимальная доменная модель и её инварианты

- **Статус:** принято
- **Дата:** 2026-11-18
- **Связано:** ADR-0002, ADR-0008, архитектура v0.2 разделы 1.3, 1.4, 5.3; реализовано в S1.2

## Контекст
S1 нужна модель документа, которую движок сможет скомпилировать в граф: Project → Event → Layer → Clip и таблица ассетов. Undo, Commands и сериализация появятся позже, но форма узлов и правила допустимого документа должны быть зафиксированы сейчас, чтобы на них опирались движок, импорт и формат файла.

## Решение
- **Узлы неизменяемы:** `NodePtr<T> = std::shared_ptr<const T>`. Правка — `modified(node, fn)`: копия узла с изменением, затем копии предков. Неизменённые поддеревья разделяются между версиями документа (структурное разделение).
- **Типизированные id:** `Id<Tag>` поверх UUID v7 (`ProjectId`, `AssetId`, `EventId`, `LayerId`, `ClipId`). Ссылки только по id.
- **Длина клипа не хранится:** она выводится из `sourceInFrames`/`sourceOutFrames` и частоты ассета (`clipTimelineLength`), поэтому не может разойтись с исходником.
- **`AssetInfo` (частота, каналы, кадры) кэшируется в проекте:** проект с пропавшими файлами знает длины своих клипов.
- **Клипы внутри слоя могут перекрываться;** перекрывающиеся клипы суммируются. Порядок клипов в слое не нормализуется.
- **Валидатор** (`findInvariantViolations` — все нарушения, `validate` — первое) проверяет: отсутствие null-узлов; ненулевые и уникальные в пределах проекта id; поддерживаемые частоты (8–768 кГц); у ассета 1–32 канала, ≥ 1 кадра и не больше 24 часов; ссылку клипа на существующий ассет; `0 ≤ sourceIn < sourceOut ≤ frames`; начало клипа ≥ 0 и конец в пределах 24 часов Event; неотрицательные fade, которые вместе помещаются в клип; gain конечный и в [−96, +24] дБ; pan в [−1, +1]; цвет 0xRRGGBB. Ошибки имеют код `invalidData` и `subject` вида `clip <uuid>.sourceFrames`.
- **Диапазоны собраны в `model/Limits.h`.** Полная тишина задаётся mute, а не бесконечным ослаблением.

## Последствия
- Каждая будущая команда обязана сохранять инварианты; тесты команд будут вызывать `validate` на результате.
- Загрузчик проекта (S2) прогоняет валидатор после миграций; нарушение — ошибка загрузки с указанием поля.
- Группы, маркеры, loop region, FX и fingerprint ассета добавляются в модель на своих этапах.

## Рассмотренные альтернативы
Хранить длину клипа на таймлайне (расходится с source-диапазоном при правках); запрещать перекрытие клипов в слое (мешает кроссфейдам и работе внахлёст, привычной для звукорежиссёров); persistent-контейнеры `immer` сразу (преждевременно до профилирования, ADR-0002).
