# Ручная проверка этапа S1 «Услышать файл» (Windows)

Сборка: установщик или `AudioForge.exe` из артефактов CI ветки `s1.6-transport`.

## Аудиоустройства (S1.5)
1. Options → Audio Settings, включить «Play test tone»: чистый тон 440 Гц.
2. Во время тона сменить устройство, частоту и размер буфера: после каждой смены тон продолжается.
3. Перезапустить приложение: выбранные устройство, частота и буфер восстановлены.
4. Выдернуть USB-интерфейс во время воспроизведения: появляется предупреждение, приложение работает. Подключить обратно: устройство снова выбрано.

## Импорт и транспорт (S1.6)
5. File → Import Audio... (Ctrl+I), выбрать WAV (лучше разные: 44,1/48/96 кГц, 16/24/32 float, длинный файл): внизу имя файла и длительность.
6. Space: воспроизведение, позиция идёт, метр двигается. Space ещё раз: стоп и возврат к позиции старта.
7. Shift+Space: пауза, позиция остаётся; ещё раз — продолжение с того же места.
8. Дослушать до конца: воспроизведение останавливается само и возвращается к началу.
9. Перетащить WAV из Проводника на окно: файл заменяется.
10. Импорт битого или не-WAV файла: сообщение об ошибке, предыдущий файл продолжает играть.
11. Метр: громкий файл зажигает красный индикатор клиппинга справа; клик по нему гасит.

## Критерий готовности S1.6
12. Буфер 256 сэмплов, длинный файл (или тестовый тон), воспроизведение 1 час. Счётчик dropouts в строке транспорта остаётся 0 (или не растёт после старта), загрузка CPU невысокая.
