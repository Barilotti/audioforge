# Ручная проверка этапа S2 «Собрать слои» (Windows)

Сборка: установщик или `AudioForge.exe` из артефактов CI ветки `s2.5-benchmarks`. Нужны 10–20 WAV разной длины и частоты (44,1/48/96 кГц), один длинный (5–10 минут).

## Импорт слоями (S2.4)
1. Выделить 10 WAV в Проводнике и перетащить на окно: 10 слоёв в том же порядке, у каждого имя файла.
2. File → Import Audio... (Ctrl+I), выбрать несколько файлов сразу: слои добавляются под существующими.
3. Перетащить вместе с WAV файл другого формата (MP3, TXT): одно сообщение со списком непринятых файлов, WAV импортированы.
4. Во время воспроизведения импортировать ещё файл: звук не прерывается, новый слой звучит.
5. File → New (Ctrl+N): все слои удалены, таймлайн пуст.

## Таймлайн и волна (S2.2, S2.3)
6. После импорта видна волна каждого клипа. У длинного файла сначала надпись «Loading...», затем волна.
7. Ctrl+колесо: зум вокруг курсора, волна остаётся чёткой на любом зуме, до отдельных сэмплов.
8. Shift+колесо: прокрутка по времени. Колесо: прокрутка слоёв. Полосы прокрутки работают.
9. Двойной клик по линейке: показать весь проект.
10. Клик и перетаскивание по линейке: позиция воспроизведения перемещается, звук следует за ней.
11. Playhead движется синхронно со звуком и не убегает за экран (вид прокручивается следом).
12. 20+ слоёв: прокрутка и зум плавные, без рывков.

## Кэш пиков (S2.1)
13. Закрыть приложение, открыть снова и импортировать тот же длинный файл: волна появляется сразу, до окончания загрузки звука.
